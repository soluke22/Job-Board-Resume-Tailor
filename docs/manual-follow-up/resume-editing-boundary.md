# Resume editing boundary

CareerOS treats the editable master resume as owner-controlled private material.
The public repository contains the application architecture, validation contracts,
and wholly synthetic examples; it does not contain an owner's resume, career
evidence, tailored recommendations, or manual edit instructions derived from them.

Teal remains the external editable source when an owner uses it. If an editable
canonical source is unavailable, CareerOS must not fabricate or reconstruct one
from incomplete material. Owner-specific edits and exported documents stay outside
the public repository.

Reconciliation into an owner workspace requires explicit owner review. Imported
content does not establish evidence authority, and claim-bearing content remains
untrusted until it passes the normal evidence and provenance workflow.

Public documentation and tests may describe the process only with generic language
or clearly synthetic identities, jobs, evidence, and metrics.
